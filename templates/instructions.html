Application Instructions

This page provides a brief user manual for the booking application.

Getting started

  • Click Open Calendar to view and manage bookings (admin login required).
  • Use Add Booking to create a new appointment.
  • Use the calendar view to edit or delete existing bookings.

Staff Instructions

  • Login: Use the Admin login on the home page to access calendar and staff features.
  • Add / Edit staff: Go to Staff → Add to create a profile (name, email, phone, hourly rate). Use edit to update details.
  • Set availability: From a staff member's availability form, set weekly availability (Mon–Sun) so the scheduler knows when they can work.
  • Manage shifts: Add shifts to schedule staff. The system warns about overlaps and helps find time suggestions.
  • Record payments: On a staff profile, add payments to track amounts paid and outstanding earnings.
  • Staff Log: Use Staff Log (protected by a staff log password) to view recent staff login entries and summary stats.

Tips

  • Admin login is required for calendar and staff operations.
  • Use the Export/print features of your browser to keep records if needed.
